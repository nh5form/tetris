# 테트리스 게임 기획서

- **문서 상태:** 초안
- **목표 플랫폼:** 데스크톱 웹 브라우저
- **게임 방식:** 1인용 클래식 테트리스
- **작성 목적:** 개발 전에 화면, 규칙, 조작, 제작 순서를 합의한다.

## 1. 게임 한 줄 소개

위에서 떨어지는 블록을 좌우로 움직이고 회전해 빈틈 없이 쌓은 뒤, 가로줄을 완성해 지우는 게임이다. 줄을 많이 지울수록 레벨이 올라가고 블록이 더 빨리 떨어진다.

## 2. 기본 게임 목표

1. 떨어지는 블록을 조작해 가로줄을 빈칸 없이 채운다.
2. 완성된 줄을 지워 공간을 확보하고 점수를 얻는다.
3. 블록이 화면 위까지 쌓이기 전까지 최대한 오래 플레이한다.
4. 가능한 한 높은 점수와 많은 줄을 기록한다.

## 3. 화면 구성

게임 화면은 플레이에 필요한 정보가 한눈에 들어오도록 다음과 같이 구성한다.

```text
┌──────────────────────────────────────────────┐
│  TETRIS                         점수  000000  │
│                                 레벨  01      │
│                                 줄    000      │
│                                              │
│              ┌──────────────┐   다음 블록    │
│              │              │   ┌────────┐   │
│              │   플레이     │   │        │   │
│              │   영역       │   │        │   │
│              │  10 × 20칸   │   └────────┘   │
│              │              │                │
│              └──────────────┘                │
│                                              │
│                 [일시정지] [다시 시작]        │
└──────────────────────────────────────────────┘
```

### 3.1 플레이 영역

- 가로 10칸, 세로 20칸의 격자로 구성한다.
- 블록이 떨어지고 쌓이는 메인 공간이다.
- 블록마다 색상을 다르게 해 모양을 쉽게 구분한다.
- 현재 조작 중인 블록의 예상 착지 위치를 흐린색 윤곽으로 표시할 수 있다. 이 기능은 기본 플레이가 완성된 뒤 추가한다.

### 3.2 정보 영역

- **점수:** 현재까지 얻은 점수
- **레벨:** 블록 낙하 속도 단계
- **줄:** 지금까지 지운 줄 수
- **다음 블록:** 다음에 등장할 블록을 미리 표시
- **게임 상태:** 시작 전, 플레이 중, 일시정지, 게임 오버를 표시

### 3.3 버튼 영역

- **게임 시작:** 첫 게임을 시작한다.
- **일시정지:** 플레이를 잠시 멈추고 같은 버튼으로 다시 진행한다.
- **다시 시작:** 현재 기록을 초기화하고 새 게임을 시작한다.
- 게임 오버 후에는 **다시 시작** 버튼과 최종 점수를 보여준다.

## 4. 블록 구성

클래식 테트리스에 사용하는 7가지 블록을 제공한다.

- I 블록: 긴 막대 모양
- O 블록: 정사각형 모양
- T 블록: T자 모양
- S 블록: 계단 모양
- Z 블록: 반대 계단 모양
- J 블록: 왼쪽 꺾인 모양
- L 블록: 오른쪽 꺾인 모양

각 블록은 한 번에 하나씩 떨어진다. 다음 블록 미리보기에는 현재 블록이 아닌 다음 순서의 블록을 표시한다.

### 블록 등장 순서

- 7종 블록이 지나치게 한 종류에 치우치지 않도록, 7종을 한 묶음으로 섞어 사용하는 방식을 기본으로 한다.
- 한 묶음의 블록을 모두 사용한 뒤 다음 묶음을 새로 섞는다.
- 이 방식은 같은 블록만 연속으로 나오거나 특정 블록이 지나치게 늦게 나오는 상황을 줄인다.

## 5. 조작 키

| 키 | 기능 | 설명 |
|---|---|---|
| `←` | 왼쪽 이동 | 블록을 한 칸 왼쪽으로 이동한다. 벽이나 다른 블록이 있으면 움직이지 않는다. |
| `→` | 오른쪽 이동 | 블록을 한 칸 오른쪽으로 이동한다. |
| `↓` | 소프트 드롭 | 블록을 한 칸 빠르게 내린다. 누른 칸 수만큼 추가 점수를 얻는다. |
| `↑` | 시계 방향 회전 | 블록을 시계 방향으로 90도 회전한다. |
| `Z` | 반시계 방향 회전 | 블록을 반시계 방향으로 90도 회전한다. |
| `Space` | 하드 드롭 | 블록을 가능한 가장 낮은 위치까지 즉시 내리고 고정한다. 이동한 칸 수만큼 추가 점수를 얻는다. |
| `P` 또는 `Esc` | 일시정지 | 게임을 멈추거나 다시 진행한다. 일시정지 중에는 블록이 움직이지 않는다. |
| `R` | 다시 시작 | 확인 절차 후 현재 게임을 끝내고 새 게임을 시작한다. |

### 조작 원칙

- 블록은 다른 블록이나 벽을 통과할 수 없다.
- 회전 결과가 벽이나 다른 블록과 겹치면 회전하지 않는다.
- 블록이 바닥 또는 다른 블록에 닿으면 자동으로 고정된다.
- 하드 드롭으로 즉시 고정한 뒤 완성된 줄을 검사한다.
- 입력 키를 오래 누르면 좌우 이동과 소프트 드롭이 반복되도록 할 수 있으나, 처음 버전에서는 한 번 누를 때 한 칸 이동해도 된다.

## 6. 점수 규칙

점수는 줄을 한 번에 많이 지울수록 크게 주고, 직접 빠르게 내린 조작에도 작은 보너스를 준다.

### 6.1 줄 지우기 점수

| 한 번에 지운 줄 수 | 기본 점수 | 실제 획득 점수 |
|---:|---:|---:|
| 1줄 | 100점 | 기본 점수 × 현재 레벨 |
| 2줄 | 300점 | 기본 점수 × 현재 레벨 |
| 3줄 | 500점 | 기본 점수 × 현재 레벨 |
| 4줄 | 800점 | 기본 점수 × 현재 레벨 |

- 한 번의 블록 고정으로 완성된 줄을 모두 계산한다.
- 예를 들어 레벨 2에서 2줄을 한 번에 지우면 300 × 2 = 600점을 얻는다.
- 한 번에 4줄을 지우는 것을 테트리스라고 부르며, 가장 큰 줄 지우기 점수를 준다.

### 6.2 낙하 보너스

- **소프트 드롭:** 한 칸 내려갈 때마다 1점
- **하드 드롭:** 한 칸 내려갈 때마다 2점
- 낙하 보너스는 줄 지우기 점수와 별도로 더한다.

### 6.3 레벨과 속도

- 10줄을 지울 때마다 레벨이 1 올라간다.
- 시작 레벨은 1이다.
- 레벨이 올라갈수록 블록이 자동으로 떨어지는 간격이 짧아진다.
- 속도는 다음 값을 기준으로 하며, 실제 조작감에 따라 테스트 중 조정할 수 있다.

| 레벨 | 자동 낙하 간격 |
|---:|---:|
| 1 | 0.80초 |
| 2 | 0.65초 |
| 3 | 0.50초 |
| 4 | 0.40초 |
| 5 | 0.30초 |
| 6 | 0.25초 |
| 7 | 0.20초 |
| 8 | 0.15초 |
| 9 | 0.12초 |
| 10 이상 | 0.10초 |

## 7. 게임 오버 조건

다음 블록을 정상적으로 등장시킬 수 없으면 게임 오버로 처리한다.

- 새 블록이 등장할 위치에 이미 쌓인 블록이 있다.
- 새 블록이 등장하자마자 다른 블록과 겹친다.
- 블록이 화면 꼭대기까지 쌓여 더 이상 새 블록을 놓을 공간이 없다.

게임 오버가 되면:

1. 블록 자동 낙하와 키 입력을 멈춘다.
2. 화면에 `GAME OVER`를 크게 표시한다.
3. 최종 점수, 레벨, 지운 줄 수를 보여준다.
4. `다시 시작` 버튼으로 새 게임을 시작할 수 있게 한다.
5. 직전 기록은 새 게임을 시작하기 전까지 화면에 남긴다.

## 8. 게임 흐름

1. 시작 화면에서 게임 시작 버튼을 누른다.
2. 첫 블록과 다음 블록이 표시된다.
3. 플레이어가 블록을 이동하거나 회전한다.
4. 블록이 바닥 또는 쌓인 블록에 닿으면 고정된다.
5. 가로줄이 가득 찼는지 확인한다.
6. 가득 찬 줄을 지우고 위 블록을 아래로 내린다.
7. 점수와 지운 줄 수를 갱신한다.
8. 10줄 단위로 레벨과 낙하 속도를 올린다.
9. 다음 블록을 새 블록으로 바꾸고 반복한다.
10. 새 블록을 놓을 수 없으면 게임 오버 화면을 보여준다.

## 9. 제작 순서

개발 경험이 없어도 진행 상황을 확인할 수 있도록, 작은 기능부터 순서대로 만든다.

### 1단계: 게임 범위와 화면 뼈대 정하기

- 데스크톱 브라우저용 1인 게임으로 범위를 확정한다.
- 플레이 영역, 점수·레벨·줄 정보, 다음 블록 영역, 버튼 위치를 만든다.
- 시작 전·플레이 중·일시정지·게임 오버 상태가 구분되도록 한다.

**완료 기준:** 빈 화면이 아닌 기본 게임 화면을 열 수 있고 각 영역의 위치를 확인할 수 있다.

### 2단계: 격자와 블록 표시하기

- 10×20 격자를 화면에 표시한다.
- 7가지 블록 모양과 색상을 준비한다.
- 블록을 플레이 영역에 표시하고 지울 수 있게 한다.

**완료 기준:** 모든 블록 모양이 화면에 올바르게 보인다.

### 3단계: 블록 자동 낙하와 고정 만들기

- 블록이 일정한 간격으로 한 칸씩 내려오게 한다.
- 바닥이나 다른 블록에 닿으면 현재 위치에 고정한다.
- 고정된 블록은 다음 블록이 움직여도 위치가 바뀌지 않게 한다.

**완료 기준:** 블록이 바닥까지 내려가고, 여러 블록이 차례로 쌓인다.

### 4단계: 기본 조작 연결하기

- 좌우 이동, 아래로 내리기, 시계·반시계 회전을 추가한다.
- 벽과 다른 블록을 통과하지 못하게 한다.
- 스페이스 하드 드롭과 일시정지를 추가한다.

**완료 기준:** 모든 조작 키가 의도대로 작동하고, 움직일 수 없는 상황에서 블록이 깨지지 않는다.

### 5단계: 줄 완성 및 삭제 만들기

- 블록을 고정할 때 가득 찬 줄을 찾는다.
- 가득 찬 줄을 삭제하고 위 블록을 아래로 이동한다.
- 한 번에 1~4줄을 지우는 경우를 확인한다.

**완료 기준:** 줄이 빈틈없이 채워지면 사라지고, 위쪽 블록이 자연스럽게 내려온다.

### 6단계: 점수, 레벨, 다음 블록 추가하기

- 줄 지우기 점수와 낙하 보너스를 계산한다.
- 지운 줄 10줄마다 레벨을 올린다.
- 레벨에 따라 자동 낙하 속도를 높인다.
- 다음 블록 미리보기와 정보 영역을 갱신한다.

**완료 기준:** 플레이 행동에 따라 점수·레벨·줄 수가 정확히 변한다.

### 7단계: 게임 오버와 재시작 완성하기

- 새 블록을 놓을 수 없는 조건을 감지한다.
- 게임 오버 화면과 최종 기록을 표시한다.
- 다시 시작 시 격자, 점수, 레벨, 줄 수를 모두 초기화한다.

**완료 기준:** 게임 오버 후 블록이 더 이상 움직이지 않고, 다시 시작하면 새 게임이 정상적으로 시작된다.

### 8단계: 플레이 감각과 화면 다듬기

- 블록 색상, 글자 크기, 버튼 상태를 정리한다.
- 키보드 조작이 직관적인지 확인한다.
- 너무 느리거나 빠른 낙하 속도를 조정한다.
- 다양한 화면 크기에서 플레이 영역과 정보가 겹치지 않는지 확인한다.

**완료 기준:** 처음 해보는 사람도 조작법과 현재 상태를 쉽게 이해할 수 있다.

## 10. 테스트 체크리스트

- [ ] 시작 버튼을 누르면 첫 블록이 나타난다.
- [ ] 블록이 자동으로 내려온다.
- [ ] 좌우 이동이 벽 밖으로 나가지 않는다.
- [ ] 회전이 다른 블록과 겹치지 않는다.
- [ ] 소프트 드롭과 하드 드롭이 작동한다.
- [ ] 블록이 바닥과 다른 블록 위에 정확히 고정된다.
- [ ] 1줄, 2줄, 3줄, 4줄 삭제가 모두 작동한다.
- [ ] 줄 삭제 후 위 블록이 빈 공간으로 내려온다.
- [ ] 점수와 줄 수가 규칙대로 증가한다.
- [ ] 10줄마다 레벨이 오르고 낙하 속도가 빨라진다.
- [ ] 다음 블록 미리보기가 실제 다음 블록과 일치한다.
- [ ] 일시정지 중에는 자동 낙하와 조작이 멈춘다.
- [ ] 새 블록을 놓을 수 없을 때 게임 오버가 된다.
- [ ] 게임 오버 후 다시 시작하면 모든 기록이 초기화된다.
- [ ] 새로고침이나 반복 플레이 후에도 화면이 깨지지 않는다.

## 11. 초기 버전에서 제외할 기능

완성도를 높이는 데 집중하기 위해 다음 기능은 첫 버전 이후로 미룬다.

- 모바일 터치 조작
- 온라인 순위표와 계정
- 효과음과 배경음악
- 스킨, 테마, 블록 모양 변경
- 홀드 블록 기능
- 리플레이와 저장 기능
- 여러 명이 함께하는 대전 모드

## 12. 첫 버전 완성 기준

다음 조건을 모두 만족하면 첫 번째 플레이 가능한 버전으로 본다.

- 키보드만으로 블록 이동과 회전이 가능하다.
- 블록이 자동으로 떨어지고, 쌓이고, 줄을 지운다.
- 점수·레벨·줄 수가 화면에 표시된다.
- 게임 오버와 다시 시작이 정상적으로 동작한다.
- 처음 보는 사람이 화면의 안내만으로 기본 조작을 이해할 수 있다.
